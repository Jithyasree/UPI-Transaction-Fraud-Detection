SMOTE class balancing + PCA dimensionality reduction — as implemented in the base paper.

🔄 SMOTE — Synthetic Minority Oversampling

Since only ~8% of transactions are fraudulent, the dataset is highly imbalanced. SMOTE generates synthetic minority-class samples by interpolating between existing fraud examples, ensuring the model does not bias toward the majority class.

  • Training set split: 80% (8,000 samples)
  • Test set: 20% (2,000 samples) — kept untouched
  • SMOTE applied only on training set (no data leakage)
  • K=5 nearest neighbors for synthetic sample generation
📉 PCA — Principal Component Analysis

PCA reduces the dimensionality of the feature space while retaining 95% of the variance. This removes noise, handles multicollinearity, and speeds up model training.
