💡 Key Findings

Why Gradient Boosting Performs Best

  • Sequential ensemble builds on prior errors
  • Handles non-linear patterns in fraud data
  • Robust to class imbalance (post-SMOTE)
  • Naturally provides feature importance scores
  • Comparable to XGBoost (used in paper)

Overfitting / Underfitting Analysis

  • Train-test gap < 5%: Ideal generalization
  • Gap > 10%: Risk of overfitting (memorizing)
  • Test accuracy < 70%: Underfitting
  • SMOTE + PCA reduce overfitting risk
  • Learning curves confirm convergence
